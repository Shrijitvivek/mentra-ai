# 🚀 Mentra AI v2 – Intelligent AI Coaching System

## 📌 Overview
Mentra AI v2 is a full-stack AI-powered application that helps users achieve their goals by generating personalized daily plans, tracking behavior, and adapting dynamically using AI.

---

## 🎯 Features

- AI-generated daily task planning
- Task tracking and progress monitoring
- Personalized AI feedback
- Memory using RAG (Retrieval Augmented Generation)
- Behavior-based adaptive planning (AI Agent)

---

## 🧠 How It Works

User → Sets Goal  
→ AI generates tasks  
→ User completes tasks  
→ Data stored (MongoDB + Vector DB)  
→ RAG retrieves past behavior  
→ AI generates personalized response  
→ Agent adjusts future plan  

---

## 🏗️ Tech Stack

- **Frontend:** React Native (Expo)
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **AI:** OpenAI / Gemini API
- **Vector DB:** Pinecone

---

## ⚡ Key Concepts Used

- Generative AI (LLMs)
- Prompt Engineering
- RAG (Retrieval Augmented Generation)
- Vector Databases
- AI Agent Logic
